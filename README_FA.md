# بسته اولیه ربات «مرکز ارزیابی روان‌شناختی فتحیان»

این بسته، اسکلت اولیه ربات تلگرام برای اجرای آزمون، ثبت پاسخ‌ها، اعلام هزینه، تأیید دستی پرداخت و خروجی گرفتن برای اکسل است.

## نکته مهم درباره پرسشنامه یانگ
فایل قبلی شما با عبارت‌هایی درباره محدودیت فروش/استفاده منتشر شده است. قبل از قرار دادن متن ۹۰ سؤال در یک ربات عمومی و دریافت پول برای تفسیر، مجوز استفاده دیجیتال و تجاری را بررسی کنید. در این بسته متن سؤال‌های دارای حق نشر قرار داده نشده است. فایل `questions.json` عمداً خالی است تا فقط محتوای دارای مجوز و کلید نمره‌گذاری تأییدشده وارد شود.

## امکانات فعلی
- منوی فارسی تلگرام
- ساختار ذخیره پاسخ‌ها در SQLite
- امکان ثبت ادعای پرداخت و تأیید/بررسی دستی توسط مدیر
- پیام به مدیر پس از تکمیل آزمون
- خروجی CSV قابل باز شدن در Excel برای مراجعان، پاسخ‌ها و پرداخت‌ها
- محاسبه میانگین ساده بر اساس نقشه نمره‌گذاری واردشده در `questions.json`؛ این روش فقط نمونه فنی است و نباید جایگزین دستورالعمل رسمی نمره‌گذاری آزمون شود.

## آنچه هنوز باید انجام شود
- وارد کردن پرسش‌ها و کلید نمره‌گذاری نسخه‌ای که مجوز استفاده آن روشن است
- تکمیل فرم مشخصات مراجع و متن رضایت آگاهانه
- تعیین مبلغ تفسیر و اطلاعات پرداخت
- اتصال به میزبان امن و آزمایش با چند حساب آزمایشی
- افزودن تولید تفسیر با هوش مصنوعی فقط پس از تعیین سرویس مجاز، سیاست نگهداری داده و بازبینی انسانی روان‌شناس
- افزودن حفاظت‌های بیشتر، پشتیبان‌گیری و سیاست حذف اطلاعات

## راه‌اندازی فنی (نیازمند یک بار تنظیم توسط شما یا فرد فنی)
1. با `@BotFather` در تلگرام ربات بسازید و توکن را بگیرید. توکن را برای هیچ‌کس در چت نفرستید.
2. Python 3.10 یا جدیدتر را روی میزبان اجرا نصب کنید.
3. در پوشه پروژه اجرا کنید:
   `pip install -r requirements.txt`
4. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN`: توکن ربات
   - `ADMIN_ID`: شناسه عددی حساب تلگرام مدیر
   - `BOT_NAME`: مرکز ارزیابی روان‌شناختی فتحیان
   - `INTERPRETATION_FEE`: مبلغ تفسیر
   - `BANK_CARD`: شماره کارت مقصد
   - `ACCOUNT_NAME`: نام صاحب کارت
5. اجرا:
   `python bot.py`

## امنیت و محرمانگی
- از رایانه/سرور شخصی امن یا میزبان معتبر استفاده کنید.
- توکن ربات را داخل کد عمومی یا گروه تلگرام منتشر نکنید.
- از جمع‌آوری اطلاعات غیرضروری خودداری کنید.
- برای اطلاعات روان‌شناختی، رضایت آگاهانه، محدودیت دسترسی، مدت نگهداری و روش حذف اطلاعات را مشخص کنید.
- این بسته نمونه اولیه است، نه محصول نهاییِ ممیزی‌شده برای استفاده بالینی.
